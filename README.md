🦾 Robotic Arm Diagnostic & Optimization Simulation

📌 Project Overview
This project simulates the performance analysis and optimization of a surgical robotic arm control system.  
It evaluates response times of key commands and demonstrates how system improvements can enhance performance and reliability.



 🎯 Objectives
- Analyze robotic arm command performance
- Identify delays in control functions
- Simulate optimization improvements
- Compare before/after system metrics


 ⚙️ Commands Tested
- move_arm
- rotate_joint
- adjust_grip


 📊 Key Results

### Initial Performance
- move_arm: 0.10s  
- rotate_joint: 0.15s  
- adjust_grip: 0.05s  

### After Optimization
- move_arm: 0.08s  
- rotate_joint: 0.12s  
- adjust_grip: 0.04s

🛠️ Tools Used
